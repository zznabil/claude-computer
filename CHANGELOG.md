# Changelog

All notable changes to this plugin. Versions follow [Semantic Versioning](https://semver.org/). The release workflow publishes the section of the tagged version as the GitHub release notes.

## [Unreleased]

### Fixed
- `element_focus` no longer reports success when the element does not hold keyboard focus: it now fails with `FocusUnconfirmed` after reading the element back.
- Windows UI Automation errors that ended in the OS text of error code 0 ("The operation completed successfully.") now say the control refused the action or is not reachable through UI Automation.

## [0.3.1] - 2026-11-26

### Added
- Addon drift check: `node scripts/check-addon-drift.mjs` lists every place that names the pinned oh-my-pi addon (`server/native.mjs`, the six `package.json` leaves, the CI cache key, `NOTICE`, README) and compares the leaves with npm `latest`. Exit 1 on a mismatch or newer upstream version, 2 when npm is unreachable; `--offline` checks only the local pins.
- Weekly `Addon drift` workflow runs the check and opens one issue on drift (no duplicates). It never changes the pin itself.
- `test/drift.test.mjs`: the check passes on the repo as shipped and fails on a broken pin.

## [0.3.0] - 2026-11-26

### Added
- `hold_keys` and `hold_mouse`: hold keys or a mouse button for 0–100 seconds, then release before the call returns, as omp's `holdKeys` and `holdMouse`. Duration is validated before anything is sent; `takeover: refuse` refuses them like other input. The call deadline grows by the hold time, so a 100 s hold is not cut off by a short `call_timeout_ms`.
- `list_windows` option `wait` (0–10000 ms): polls every 100 ms and returns as soon as a window matches, as omp's `window({ wait })`.
- `test/live-hold.mjs`: live check of all three on a scratch WinForms window; it works while the screen is locked.

### Changed
- 33 tools (12 read-only, 21 action).


## [0.2.0] - 2026-11-26

### Added
- Native Antigravity CLI (`agy`) plugin in the same repository: `.antigravity-plugin/plugin.json`, `mcp_config.json` and `rules/AGENTS.md`. No conversion step.
- Host detection and a shared data folder: `CLAUDE_PLUGIN_DATA` (Claude Code), `PLUGIN_DATA` (agy), else `~/.cache/claude-computer`.
- `settings.json` in the plugin data folder for `takeover`, `max_width`, `max_height`, `call_timeout_ms` and `install_timeout_ms`. Environment variables win over it.
- `capabilities` reports `serverVersion`, host, data folder, settings and where each setting came from.
- Plugin icon (`assets/icon.png`), generated by `scripts/make-icon.mjs`.
- `test/live-agy.mjs`: agy itself drives a scratch Notepad round-trip.
- CI on Linux, Windows and macOS, manifest checks for both hosts, and a tag-driven release workflow.

### Changed
- `menu_items` is no longer marked read-only: on macOS, reading a menu first makes its window key.
- The `refuse` takeover setting now refuses the same calls as oh-my-pi, including raise actions and, on macOS, calls that open a menu.
- Tool calls and the first-run addon install have hard timeouts. The native session closes when the host disconnects or on SIGINT/SIGTERM.
- `list_windows` prefers exact app names, and `open_application` takes `app` and `reveal` (macOS).

## [0.1.0] - 2026-11-26

### Added
- Claude Code plugin with one MCP server and 31 tools: displays and windows, screenshots, accessibility trees with element refs, element actions, background-first native input, clipboard and capabilities.
- Backed by the prebuilt oh-my-pi desktop addon (`@oh-my-pi/pi-natives` 19.2.1, MIT), installed on first use.
